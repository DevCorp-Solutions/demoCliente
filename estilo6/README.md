# Miga

Estilo 6, concepto independiente de demostración. No modifica otros estilos.

Servir la carpeta del repositorio con `python -m http.server 8080 --bind 127.0.0.1` y abrir `/estilo6/`. Vista móvil interactiva: `/estilo6/preview-mobile.html`.

Carta, precios y alérgenos ficticios. El configurador solo calcula una combinación; no realiza pedidos ni pagos.

Fotografías locales de referencia y atribuciones en `credits.html`.
