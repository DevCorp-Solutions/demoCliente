# Órbita

Estilo 7, concepto independiente de demostración. No modifica otros estilos.

Servir la carpeta del repositorio con `python -m http.server 8080 --bind 127.0.0.1` y abrir `/estilo7/`. Vista móvil interactiva: `/estilo7/preview-mobile.html`.

Carta, precios y alérgenos ficticios. El configurador solo calcula una combinación; no realiza pedidos ni pagos.

Ilustraciones SVG originales incluidas en `images/`.
