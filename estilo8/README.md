# Tercio · Estilo 8

Concepto ficticio de cervecería de barrio. Azulejos, azul cobalto, pizarra de seis grifos y aperitivos.

Abrir desde el servidor del repositorio: `/estilo8/`. Vista móvil interactiva: `/estilo8/preview-mobile.html`.

HTML, CSS y JavaScript sin compilación. Fuentes de Google Fonts con alternativas del sistema. Carta, precios, graduaciones y alérgenos de demostración; verificar antes de adaptar a un negocio real. Sin pedidos ni pagos. Selección de cerveza y tamaño, fichas de tapas y selector de los ocho estilos. Fotografías locales y atribuciones en `credits.html`. Ilustración de caña creada en CSS.
